# images

- `posters/` — โปสเตอร์กิจกรรม (ตั้งชื่อไฟล์ตาม event id เช่น `11.jpg`)
- `certificates/` — เทมเพลตเกียรติบัตรที่อัปโหลดจากหน้า "สร้างกิจกรรม"
- `placeholder-event.jpg` — ภาพสำรองเมื่อกิจกรรมไม่มีโปสเตอร์ (ใส่ไฟล์จริงที่นี่)

Binary image assets are intentionally not committed by this scaffold — drop real files into these folders.
