# CPSU ETMS · ระบบจัดการกิจกรรมและการอบรมแบบครบวงจร

ระบบเว็บสำหรับจัดกิจกรรมและการอบรมของภาควิชาคอมพิวเตอร์ คณะวิทยาศาสตร์ มหาวิทยาลัยศิลปากร
ครอบคลุมตั้งแต่ประกาศกิจกรรม รับสมัคร ชำระค่าลงทะเบียน เช็คชื่อ แบบประเมิน ออกเกียรติบัตร จนถึงรายงานและงบประมาณ

## ผู้ใช้งานและสิ่งที่ทำได้

| บทบาท | ทำอะไรได้ |
|---|---|
| **นักศึกษา** | สมัครสมาชิกด้วยอีเมล `@silpakorn.edu` (ยืนยันด้วยรหัส OTP) · ค้นหาและลงทะเบียนกิจกรรม · ชำระเงิน/แนบสลิป · เช็คอินออนไลน์ · ดูประวัติ · ทำแบบประเมิน · ดาวน์โหลดเกียรติบัตร |
| **อาจารย์** | ทุกอย่างของผู้เข้าร่วม (ไม่เสียค่าลงทะเบียน) · ดู "กิจกรรมที่รับผิดชอบ" และรายงานของกิจกรรมที่ตนเป็นผู้ประสานงาน (ดูอย่างเดียว) |
| **ผู้จัดกิจกรรม** | สร้าง/แก้ไข/ลบกิจกรรม · เปิด-ปิดรับสมัคร · ดูรายชื่อ · เช็คชื่อรายวัน · ตรวจสลิปและคืนเงิน · ตั้งแบบประเมิน · ออกเกียรติบัตร · แดชบอร์ด รายงาน งบประมาณ · คลังโปสเตอร์สรุปข่าว · Blacklist |
| **ผู้ดูแลระบบ** | ทุกอย่างของผู้จัด (ทุกกิจกรรม) · จัดการผู้ใช้และบทบาท · ระงับบัญชี · ตั้งค่าเกียรติบัตรกลาง · บันทึกการใช้งานระบบ |

ทุกบทบาทมีกระดิ่งแจ้งเตือน และระบบมีงานตามเวลา (ทุก 15 นาที) สำหรับเตือนก่อนวันกิจกรรม เตือนงานค้าง
และนับการขาด (ขาดครบ 3 ครั้งในปีงบประมาณจะถูกระงับสิทธิ์ลงทะเบียนอัตโนมัติ)

## รันบนเครื่อง (สำหรับพัฒนา)

ต้องมี Docker, Go 1.26 และ Node.js 18 ขึ้นไป

**1. ฐานข้อมูล**

```bash
docker run -d --name cpsu-etms-mysql -p 3306:3306 \
  -e MYSQL_ALLOW_EMPTY_PASSWORD=yes -e MYSQL_DATABASE=cpsu_etms mysql:8.0
# รอสัก 20 วินาทีให้ MySQL พร้อม แล้วสร้างตารางและข้อมูลตัวอย่าง (ตามลำดับนี้)
for f in schema seed demo_organizer seed_teachers seed_demo_titles; do
  docker exec -i cpsu-etms-mysql mysql --default-character-set=utf8mb4 -uroot cpsu_etms < database/$f.sql
done
```

**2. Backend** (พอร์ต 4000)

```bash
cd backend
cp .env.example .env      # ตั้ง JWT_SECRET เป็นข้อความสุ่มยาวๆ
go run .
```

ถ้าไม่ได้ตั้ง `SMTP_HOST` รหัส OTP สำหรับสมัครสมาชิก/ลืมรหัสผ่านจะแสดงใน log ของ backend (บรรทัด `[mail:dev]`) แทนการส่งอีเมล

**3. Frontend** (พอร์ต 3000)

```bash
cd frontend
npm install
npm start
```

เปิด http://localhost:3000
