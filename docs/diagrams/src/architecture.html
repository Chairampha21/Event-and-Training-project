Sสำหรับนักศึกษา / ผู้เข้าร่วมกิจกรรม

  • ค้นหาและดูรายละเอียดกิจกรรม
  • ลงทะเบียน (Onsite / Online, ยืมโน้ตบุ๊ก, แจ้งอาหาร)
  • ชำระค่าลงทะเบียน · แนบสลิป
  • ยกเลิกการลงทะเบียน
  • เช็คอินออนไลน์ด้วยลิงก์
  • ดูประวัติการเข้าร่วมกิจกรรม
  • ทำแบบประเมินกิจกรรม
  • ดาวน์โหลดเกียรติบัตร

Oสำหรับผู้จัดกิจกรรม

  • สร้าง / แก้ไข / ลบกิจกรรม
  • เปิด / ปิดรับสมัคร
  • ตรวจสอบรายชื่อผู้สมัคร
  • เช็คชื่อผู้เข้าร่วม (รายวัน)
  • ตรวจสลิป · บันทึกการคืนเงิน
  • ตั้งแบบประเมิน · ดูผลประเมิน
  • ออกเกียรติบัตร (แม่แบบ / ผู้ลงนาม)
  • แดชบอร์ด · รายงาน · งบประมาณ
  • คลังโปสเตอร์สรุปข่าว (SAR)
  • จัดการ Blacklist

Aสำหรับผู้ดูแลระบบ

  • จัดการข้อมูลผู้ใช้งาน
  • กำหนดบทบาท / สิทธิ์ผู้ใช้
  • ระงับ / คืนสิทธิ์บัญชี
  • จัดการกิจกรรมทั้งหมดในระบบ
  • ตั้งค่าเกียรติบัตรกลาง
  • ตรวจสอบบันทึกการใช้งาน
  • ตรวจสอบภาพรวม · สรุปเรื่องค้าง
